# Mock Data

Mock data digunakan agar tim frontend dapat membuat UI dan logic aplikasi tanpa menunggu backend selesai.

## File

| File | Keterangan |
|---|---|
| `menu.json` | Data menu contoh |
| `table.json` | Data meja dan QR token contoh |
| `options.json` | Data opsi customization |
| `order-request.json` | Contoh payload order |
| `invoice.json` | Contoh response invoice |

## Catatan

Mock data harus mengikuti API Contract agar saat backend selesai, frontend cukup mengganti data source dari mock ke API service.
